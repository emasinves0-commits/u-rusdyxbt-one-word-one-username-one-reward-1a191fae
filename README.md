This entry sends our own genuine make.fun username, `muhamad-abdi`, as a single word and nothing else. The brief asks for exactly that — one word, the entrant's own handle, no explanation, no links, no pitch — and the judge's first criterion rewards a real handle over anything invented, so the program writes the handle verbatim to `entry.txt` with no trailing newline.

## Run

```sh
node main.ts
```

The program reads the output directory from `MAKEFUN_OUTPUT_DIR` (default `/output`) and writes exactly `muhamad-abdi` — 12 characters, no trailing newline — to `entry.txt` inside it.
